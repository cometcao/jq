## 关键决定（本轮）

- **没有优先级标签了**（ADR-024）：P0a/P0b/P1/P2 全删。数据是否可得不由框架决定，所以接入顺序由附录 C 的 G1/G2/G3 决定；阶段只表达能力依赖。
- **六环是基本面的内部排序**（ADR-019），比价是第二个面；事件面排在两者之后，C1 有日程指针回流（ADR-020）。
- **比价锁在事实域**（ADR-022）：分支假设值不进比价。
- **事实记录四字段**（ADR-023）：subject / channel / proves / does_not_prove。

## 附录 B：比价输出 schema（D02，V2.145.0 定稿）

```json
{
  "compare_id": "比价记录唯一标识",
  "compare_type": "time_self（时间自比）/ cross_sectional（空间互比）",
  "compare_operation": "ratio / difference / spread / percent_change",
  "operand_order": "被减数 − 减数 或 分子 / 分母（如 M2同比 − M1同比、USD/CNH − USD/CNY）；未声明不得输出",
  "result_form": "point_value / percentile / rank",
  "universe": "rank 必填：对照全集（全市场/指定板块集合/指数成分）与排序方向",
  "reference": "偏离度必填：对比基准（窗口均值/中位数/上期值/参考线）；非偏离度填 null",
  "anchor": {        // 七锚，缺一不得输出
    "同质锚": "双方 attribute 与 transform 均相同",
    "属性锚": "两个 indicator_id 的 attribute 定义一致",
    "口径锚": "双方 caliber_version 与 comparable_from",
    "窗口锚": "观察窗口（window），起点须覆盖双方 comparable_from",
    "层级锚": "同层，或细层 ↔ 其所属粗层（归属锚见下）",
    "归属锚": "跨层时必填：归属来源与版本（成分表/行业分类）",
    "量纲锚": "单位、币种、频率声明"
  },
  "inputs": [
    { "ref_type": "indicator_id | compare_id", "ref": "...", "layer": "...", "data_period": "..." }
  ],
  "current_state": { "对比结果": "...", "数值": "...", "数据所属期": "..." },
  "series": [
    { "data_period": "...", "compare_value": "...", "value_kind": "return/level/ratio/count" }
  ],
  "data_period": "本次比价对齐的主所属期（必需）",
  "window": "观察窗口",
  "value_kind": "结果序列的类型（决定是否可渲染折线，见第七节 V1/V2）",
  "source_tier": "...",
  "fallback_flag": "...",
  "missing_type": "...",
  "value_type": "...",
  "rule_status": "ratified/draft",
  "...": "第四节其余统一字段（observation_time、release_date、update_frequency、source_timestamp）"
}
```

规则：inputs 只记引用与元数据，**不呈现输入方原始数值**；series 为对比结果序列，按第七节 V1/V2 判据决定是否渲染；任一锚缺失或不一致、operand_order 缺失（差值/比值类）、rank 缺 universe、偏离度缺 reference 时，该比价不输出（F06）。叠加比价（内层空间互比、外层时间自比）通过 inputs.ref_type=compare_id 实现。**事实域封闭（ADR-022）：** inputs 的 ref 必须指向已落地的两方事实记录或既有 compare_id；不得引用假设值、事件分支结果或 `prev_value`——分支定义条件不生成比价。

**默认窗口：** 见第七节（时间自比 20 个可比期、分位 3 年且不早于 comparable_from、相关系数 60 个可比期）；窗口锚未声明时按该默认值执行，并在元信息段注明“默认”或“用户指定”。

## 附录 F：层归属与骨架

### F.1 市场层（六环，ADR-019）

C1 政策设定、C2 资金供给、C3 资金价格、C4 场内杠杆与资金池、C5 主体行为（外部/机构/散户）、C6 市场结果。六环是资金通道顺序，不是因果断言。外部条件（VIX/DXY/美国 10Y）为背景，不占环位。每条事实必须带 subject / channel / proves / does_not_prove。

### F.2 板块层（同名同序六环 + 三条归属规则）

板块层六环与市场层同名同序，但内容重定义：C1 行业政策、C2 供给份额（派生，非独立采集）、C3 相对贵贱（估值水平 + 全市场估值差）、C4 场内杠杆与资金池（板块层默认空环）、C5 主体行为（加总项最重）、C6 结果（最强）。定义与状态词见第六节。

成立前提是三条归属规则：**R1** 成分表版本（无版本不输出时间自比）、**R2** 加总口径（等权/加权、剔除规则、覆盖率下限）、**R3** 跨版本处理（禁拼接，只分段或截面）。

### F.3 个股层（**v1 不做**）

原"公司财务 / 公司资金 / 公司情绪 / 公司公告状态 / 公司分类"五类保留为参考，等板块层定案后再评估是否套用六环。

### F.4 归属唯一性

每个 indicator_id 只有一个 layer。同一指标出现在多层清单时以更细层为注册层，粗层只引用同一 indicator_id（第三节规则）。板块内相关系数、个股价格序列、板块成交额与换手率一律注册在板块层；市场层只保留跨板块横截面观测与引用（见第六节）。

### F.5 跨层引用规则

粗层引用细层指标时，记录中 layer 填**注册层**（细层），被引用处的分组归属由清单决定；跨层只并列陈列，不做判定、不传递结论（F07）。

**`verified_by`（V2.145.0 增补）**：`source_tier=B` 的记录必须携带该字段（官方核对链接，取自 `data/official/<id>.jsonl` 的 `source_url`）；C 类记录留空。

## E.2 定稿流程

1. 用户逐条给出结论（同意 / 改成 X / 删掉）。
2. 改正文对应处的措辞与编号，版本号升位，`rule_status` 由 draft 改 ratified。
3. 在 `CHANGELOG.md` 新增一条，写明"哪条草案 → 定稿结论"。
4. 若该条款在第一阶段已被使用，同步更新回归样本与校验器断言。

## E.3 与禁令的关系

- 未定稿条款不得作验收判据 = **F15**。
- 用 draft 条款产出结果而不标 `rule_status` = 违反 `05_输出与校验契约.md` 的校验项 V-h，输出被拒。

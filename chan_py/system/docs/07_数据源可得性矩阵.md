> 本文件是《全景客观金融分析工作台》的一部分。节号与附录字母全局连续，文件地图见 `../00_README_文档地图.md`。

**这份文件为什么排第一：** 框架里所有"可得"的假设都在这一张表上。表里判"无路径"的条目，后面写的 schema、Skill、渲染都是纸上设计。

**V2.139.0 重写说明（重要）：** 本表原来是**建取数层之前的判断**（结论是"C2/C3/C4 空环、G1 为 0、必须换源或缩范围"）。2026-11-21 已用 akshare 实测 19 个指标，**原结论基本被推翻**——C2/C3/C4/C5/C6 全部有值，只剩两格真空。本版把每一行改成**实测记录**，旧结论与"三选一"作废（见 `CHANGELOG` V2.139.0）。

**三档判定（每行必须落到其中一档）：**

| 档 | 含义 | 后续动作 |
|---|---|---|
| G1 可得 | 当前环境有明确取数路径，不需额外授权或采购 | 直接接入 |
| G2 需授权 | 有路径但需付费/授权/申请（含需自建爬虫维护的官方源） | 报成本与工期，用户决定买不买 |
| G3 无路径 | 当前环境无任何端点，也无可接受的替代源 | 标 missing，走止损或改范围，**不得用近似量顶替** |

**档位与数据分级是两件事：** G1/G2/G3 说的是"能不能拿到"，A/B/C/D 说的是"拿到的东西能不能单独支撑状态词"（D03）。akshare 抓来的数据是 **G1 可得**，但**分级为 C**（开源库一律 C），要进状态词须在 `data/c_reasons.json` 登记理由；升 B 须官方直连 + 抽样核对。

## C.3 结论（V2.139.0 实测）

1. **空环只剩两格：C4 现金池（客户保证金）、C5 外部（北向）。** 六环其余全部有值：C1（LPR）、C2（M2/M1/财政存款/贷款同比）、C3（DR007/10Y/汇率/股息率）、C4（两融）、C5（散户+机构）、C6（参与度/广度/结构）。
2. **成本结构变了：从"买数据"变成"对账"。** 19 个指标全部免费获得；代价是每项要标 C 并登记理由，升 B 要官方直连 + 抽样核对（目前 2 项已升 B：DR007、汇率）。
3. **"三选一（换源 / 缩范围 / 只做可做层）"作废。** 当时的前提是"C2/C3/C4 拿不到"，现已不成立；免费路线已于 V2.17–V2.24 落地（ADR-036/ADR-037）。
4. **真正的剩余风险不是"有没有数据"，而是"数据稳不稳"。** 实测：东财会限流（5–40 分钟）、新浪会返回截断数据（上证只到 2019）、腾讯稳但慢（26 秒）、同花顺/中证/央行/拆借中心稳。

## 财经媒体的数据分级裁定（2026-11-23）

问题："老牌金融/经济网站的数据算不算 B 级？"——**不算，封顶 C 类**。

| 源类型 | 裁定 | 理由 |
|---|---|---|
| 部委 / 交易所 / 统计局 / 央行 | A/B 候选 | 法定发布主体，可直连核对 |
| **巨潮资讯 cninfo** | A/B 候选（特殊） | 证监会指定披露平台，公告原文=法定披露 |
| **证券时报 / 中证报 / 上证报 / 东财 / 同花顺** | **C 类** | 二次加工媒体：可能漏、可能改写，不是披露主体 |

**B 类的两个条件缺一不可**：① 代码直连官方域名；② 有抽样对账记录。媒体域名不满足 ①，所以再"老牌"也只能是 C 类，状态里必须带 `〔C 类·…〕` 标注。

## B 级的两种对账方式（2026-11-23 补充）

原先只写"数值与官方逐项比对"，实测发现对**检索类/条数类**数据不适用。补第二类：

| 方式 | 适用 | 判据 |
|---|---|---|
| ① **数值比对** | 有官方同口径数值 | 我方值 == 官方接口值 |
| ② **原文抽样可核** | 检索类（公告条数、事件清单） | 抽 N 条结果，其**原文链接可达且标题/日期一致**（原文即法定披露） |

**巨潮资讯（cninfo）按方式 ② 升 B**：证监会指定披露平台，公告原文属于法定披露；对账时抽 3 条 PDF 验证可达 + 标题一致。

`INST_INSIDER_NET`（产业资本增减持，公告条数口径）因此成为 B 类。

## 板块估值映射覆盖（2026-11-24）

中证指数官网「行业」分类共 **511 个**指数（`indexClassify=行业`），实测其中多数提供 `indicator.xls`（含市盈率/股息率）。

**已写入 `data/sector_index_map.json` 的映射：45 个板块**（一级 30 个 + 二级 15 个），全部验证过 PE 可取。

映射原则（只收语义明确的）：

| 收 | 不收 |
|---|---|
| 同名或同域（半导体→全指半导体、银行→银行行业） | **上位行业替代**（工业金属↛全指工业、消费电子↛全指消费） |
| 一级行业对一级行业（电子→电子行业、汽车→汽车汽配行业） | 跨行业错配（电力↛电力设备、林业↛纸类林业） |
| 名称带"行业"的新体系（932xxx）与全指（H30xxx） | AMAC / 港股通 / 500 / 380 等子集或跨市场口径 |

**未覆盖的 86 个申万二级板块**：中证行业分类更粗（如"半导体"只到二级，再往下如"模拟芯片"没有对应指数），只能留 `C3 不可读`。

## TLS 校验豁免清单（V2.139.0）

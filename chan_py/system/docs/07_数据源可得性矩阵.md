# 07 数据源可得性矩阵（附录 C）· V2.22.0

> 本文件是《全景客观金融分析工作台》的一部分。节号与附录字母全局连续，文件地图见 `../00_README_文档地图.md`。

**这份文件为什么排第一：** 框架里所有"可得"的假设都在这一张表上。表里判"无路径"的条目，后面写的 schema、Skill、渲染都是纸上设计。所以第零阶段的第一个交付物是它，不是环境清单，也不是渲染链路。

**三档判定（每行必须落到其中一档）：**

| 档 | 含义 | 后续动作 |
|---|---|---|
| G1 可得 | 当前环境有明确取数路径，不需额外授权或采购 | 直接进第一阶段 |
| G2 需授权 | 有路径但需付费/授权/申请（含需自建爬虫维护的官方源） | 报成本与工期，用户决定买不买 |
| G3 无路径 | 当前环境无任何端点，也无可接受的替代源 | 标 missing，走止损或改范围，**不得用近似量顶替** |

**判定人：** 每行有 owner；矩阵完成 = 五列（路径/授权/频率/口径断点/缺失处置）均非空 + 每行有结论档 + 末尾有"三选一"建议。

## C.3 结论（第零阶段必须原样报给用户）

1. **C1 没有 G1 条目；C6 有 G1；C2、C3、C4 目前为空环。** C2 的 M2/M1/社融全 G2/G3；C3 的 DR007/国债全 G2/G3；C4 的两融与保证金均非 G1；C6 的 #10 成交额、#18 涨停家数、宽基指数日线与板块行情为 G1。按 ADR-024 不设先后——先接 G1、把空环显式标注，链能跑多长跑多长。
2. **零成本可得项：#10 全市场成交额、#18 涨停家数、宽基指数与 ETF 日线、板块行情。** 足够验证比价能力（一个时间自比 + 一个排名），但支撑不了 C2/C3/C4。
3. 其余 16 项里 G1 为 0 项，多数需要官方直连或付费数据商。

**三选一（用户拍板，任一选择都写进 CHANGELOG）：**

- **A 换源**：接商业终端（B 类）或官方直连（A 类，自建爬虫维护）。代价：授权费用与爬虫维护；收益：C2/C4 的空环可在 1–2 周内补上。
- **B 缩范围**：把第一阶段改为"宽基指数日线 + 融资余额增速（改接交易所汇总）+ 全市场成交额"，M2/M1 先留空环。代价：剪刀差这条主线推迟；收益：当天可开工。
- **C 只做可做层**：跳过市场层资金闭环，先做事件面（第四阶段提前）与板块层（第五阶段），资金类指标全部以"当前无源"呈现。代价：平台定位变成"事件 + 板块"，与"根源目标：资金"的设定冲突。

## C.4 补齐路径与代价量级

| 路径 | 数据分级 | 覆盖 | 代价量级 | 备注 |
|---|---|---|---|---|
| 官方直连（央行/统计局/中债/同业拆借中心） | A | M2/M1/社融/存款/财政存款/Shibor/DR007/中债 10Y | 开发 + 长期维护（页面改版即断） | 最稳的口径来源，但**需要一个人长期盯** |

| 开源数据库（akshare 等） | C | 覆盖面广但不保证稳定与口径 | 免费；随时可能失效 | 只能作过渡，事实记录必须标 C，且不得伪装为 A/B（F10） |
| 用户上传 CSV/Excel | A/B/C 按溯源 | 任意 | 人工 | 三步判定见第十五节；传闻不得作数值事实 |
| 人工录入 | 设计内 | 事件日历、政策状态 | 人工 | **只允许**这两类（8.1 与第六节），不得用于高频数值事实 |

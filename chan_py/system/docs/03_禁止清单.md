## 45. 歧义方向词：压力 / 阻力 / 支撑（V2.120.0 新增）

**禁止**在分支影响、状态、读法里使用「上行压力 / 下行压力 / 阻力位 / 支撑位」。

理由：中文金融语境里「上行压力」有两种相反读法——
1. 有力量在**推高**（upward pressure，倾向上涨）；
2. 上方遇到**阻力**（resistance，上涨受限）。

同一句话能读出相反含义，等于没写。**一律改成机械映射**：

| 禁用 | 改用 |
|---|---|
| 10Y 面临上行压力 | 该分支对应收益率**同向上移**（收益率上行 = 债券价格下行；不预测实际落点） |
| 有支撑 / 有阻力 | 直接写数值比较（`x > 前值`）或「区间高低」 |

回归测试 T27 会在 `scenarios.py`、历史分支记录、事件卡三处扫描这些词。

## 46. 可枚举的歧义词全部机械拦截（V2.120.0）

除第 45 条的「压力/阻力/支撑」外，以下词一律禁用（见 `scripts/ambiguity_scan.py`）：

| 类别 | 禁用词 | 替代 |
|---|---|---|
| 无阈值程度 | 明显 / 显著 / 大致 / 大约 / 左右 | 写具体数值 |
| 预测 | 预计 / 有望 / 应该 / 可能 | 只写条件分支 |
| 对手方叙事 | 流入 / 流出 / 主力 | 净买额 / 余额增减 / 具体口径 |
| 指代不明 | 前者 / 后者 / 该指标 / 该口径 | 重写指标全名 |
| 时间不明 | 近期 / 目前 | 写具体数据期 |
| 常态判断 | 通常 | 「按登记规则」 |

**另两条硬规则**：
1. **「上一期 / 前值」必须同行带日期或数值**（否则读者不知道跟哪天比）；
2. **读法禁用主观程度词与比喻**（很薄 / 缩得更快 / 在另一边 / 只能来自 / 几乎一个价）。

扫描器会遍历最新状态页、两张卡片、全部分支记录；`test_regression.py` 的 T28 每次跑一遍。

## G.1 两个判据：attribute 与 transform

同质锚由**两个字段同时相等**决定（ADR-017）。只比 attribute 会把"同名不同物"判成同质——例如 M2 同比与 CPI 同比都是"增速"，但一个量货币、一个量价格。

**attribute（被度量的基变量属性）：**

| ID | 属性 | 定义 | 典型指标 |
|---|---|---|---|
| A1 | 价格水平 | 可交易的报价或点位本身 | 指数点位、ETF 价、个股收盘价、CPI 指数、DXY |
| A2 | 收益率 / 利率水平 | 持有资产或借入资金的回报率、市场利率 | 中国 10Y、美国 10Y、Shibor、DR007、LPR、股息率、信用利差 |
| A3 | 期间流量 | 一段时期内发生的金额 | 全市场成交额、成交总额、融资买入额、北向盘后成交总额、龙虎榜净买、ETF 净申赎 |
| A4 | 时点存量 | 某一时点的余额或持有量 | 两融余额、M1/M2 余额、各项存款、保证金、北向季度持股 |
| A5 | 占比 / 比率 | 部分与整体、或两个同量纲量之比 | 板块成交占比、融资买入占比、定期化比例、集中度、折溢价率、小单占比 |
| A6 | 计数 | 个数、家数、笔数 | 涨停家数、新开户数、成交笔数、涨跌家数、关注度 |
| A7 | 统计量 | 由两个序列算出的统计特征 | 相关系数、离散度 |
| A8 | 汇率 | 两种货币的兑换比例 | USD/CNY 中间价、USD/CNH 即期 |
| A9 | 估值倍数 | 价格与基本面量的比值 | PE、PB |
| A10 | 波动率 | 收益率的离散程度 | VIX |
| A11 | 定性状态 | 无法数值化、以枚举描述的状态 | 行业监管状态、外汇政策状态 |
| A12 | 事件 / 动作 | 已发生的政策动作或未来事件 | 降准/降息/OMO/MLF 动作、事件日历条目 |

**transform（同一基变量上的变换）：**

| ID | 变换 | 含义 | 典型写法 |
|---|---|---|---|
| T1 | level | 原值（水平值） | M1 余额 112.45 万亿 |
| T2 | yoy | 同比 | M2 同比 7.2% |
| T3 | mom | 环比 | 社融环比 |
| T4 | cum | 累计 / 年初至今 | 累计成交额 |

**同质判据：** `a.attribute == b.attribute and a.transform == b.transform`，否则拒绝计算（F06）。据此：M2 同比(A4,T2) 与社融同比(A4,T2) 同质；M2 同比(A4,T2) 与 CPI 同比(A1,T2) **不同质**；股息率(A2,T1) 与 中国 10Y(A2,T1) 同质；两融余额(A4,T1) 与 融资净买入(A3,T1) **不同质**。

## G.5 算子白名单与锚校验（可直接实现）

```python
ALLOWED = {
  # attribute: 允许的 compare_operation（对原始水平值）
  "A1": set(),                      # 价格水平：原始值不允许任何算子，只能先 percent_change
  "A2": {"ratio", "difference", "spread", "percent_change", "rank"},
  "A3": {"ratio", "difference", "percent_change", "rank"},
  "A4": {"ratio", "difference", "percent_change", "rank"},
  "A5": {"difference", "percent_change", "rank"},
  "A6": {"ratio", "difference", "percent_change", "rank"},

def same_class(a, b):
    """同质锚 + 属性锚：基变量属性与变换都必须相同（ADR-017）"""
    return a.attribute == b.attribute and a.transform == b.transform

def ownership_ok(a, b):
    """归属锚（ADR-013）：同层直接通过；跨层只允许细层 ↔ 其所属粗层"""
    if a.layer == b.layer:
        return True
    fine, coarse = (a, b) if a.layer_rank > b.layer_rank else (b, a)   # 个股3 > 板块2 > 市场1
    return coarse.indicator_id in fine.ownership.get("parents", []) and fine.ownership.get("source_version")

def check(a, b, op, result_form, window, operand_order, universe=None, reference=None):
    if not ownership_ok(a, b):                     return "归属锚不符（跨层但无归属关系或未声明来源版本）"
    if not same_class(a, b):                       return "同质锚不符（attribute 或 transform 不同）"
    if a.unit_group != b.unit_group and not declared_convertible(a, b):
                                                   return "量纲锚不符（未声明换算）"
    if not window_covers(window, a.comparable_from, b.comparable_from):
                                                   return "窗口锚不符（跨口径断点）"
    if a.caliber_version != b.caliber_version and not comparable(a, b):
                                                   return "口径锚不符（caliber_version 不同）"
    if op in {"difference","spread","ratio","percent_change"} and not operand_order:
                                                   return "算子顺序未声明"
    if result_form == "rank" and not universe:     return "universe 未声明"
    if op not in ALLOWED[a.attribute] and op != "percent_change":
        # A1 的 percent_change 单独放行：结果是 return，可进入下一步 difference/rank
        return "算子白名单拒绝（%s 不支持对水平值做 %s）" % (a.attribute, op)
    return "OK"
```

**输入前置检查（ADR-022）：** 调用 `check` 之前先验证两方都是**已落地的事实记录**（`status=active`，且不是事件分支的 `prev_value`）；否则直接拒绝，返回"事实域封闭"。

**使用顺序：** 先 `percent_change`（产出 value_kind=return，attribute/transform 不变），再 `difference` / `rank`。这条链就是"板块 ETF 对宽基指数只许收益率差或排名"的实现方式（ADR-001）。

**归属来源版本（ADR-013）：** 跨层比价时，`ownership.source_version` 必须记录用了哪一版成分表/行业分类（如"申万行业分类 2021 版""中证指数成分 2026-10 调整后"）。成分变更后旧比价不可与新比价直接比较名次。

## G.6 变更规则

1. 新增指标必须挂已有 attribute + transform + channel + subject；要新开 attribute 或新开环，等同升框架版本。
2. 修改某指标的 attribute / transform / channel = 口径变更，必须新增 caliber_version，历史记录不重写。
3. **不得为了让某组对比"能算"而改 attribute / transform，也不得为了让指标"排得进去"而改 channel**——那是判断，不是口径。
4. 本表增删改一律在 `CHANGELOG.md` 记一条，并同步回归样本。

> **注册策略（ADR-040）**：指标**只增不减**。免费源不稳定可接受；失败当次跳过、不阻断其他指标；**不做源健康度记录**。只有口径失效或官方停发才移出。

> **序列形态登记（ADR-041）**：指标按形态分「波动 / 累积 / 季节 / 阶梯 / 区间汇总」，卡片图形随之切换（位置条 / 增速 / 较均值 / 档位 / 不画）。登记在 `data/series_shape.json`，规则见 `render.md` R9。

## 附录 D：输出模板与渲染前校验（实现层）

### D.1 六段模板（与第九节对应）

| 段 | 内容 | 必需列/字段 |
|---|---|---|
| ① 事实层 | 按六环排列的事实表：**C1 政策设定 → C2 资金供给 → C3 资金价格 → C4 场内杠杆与资金池 → C5 主体行为（外部→机构→散户）→ C6 市场结果 → 背景（外部条件）**；环内按 subject 分组；空环保留环名并标 missing_type | 白名单列：指标｜数值｜单位｜data_period｜release_date｜source_tier｜missing_type｜observation_time｜**subject｜channel｜proves｜does_not_prove**｜capital_path（派生统计量才加 window / series_frequency）。白名单之外一律不加，示例见 V-i |
| ② 对比层 | 比价结果表 + 可渲染的 series 折线；只吃已落地事实（事实域封闭） | 比价名称｜compare_operation｜operand_order｜result_form｜结果｜window｜universe/reference（如适用）｜背离（同向 / 存在背离：多数方向 + 反向指标名 / 方向分歧） |
| ③ 事件情景层 | **首行固定为"与 C1 指针一致：未来 30 天政策与发布日程 N 项"**；随后是未来 30 天日历表（仅"未来预定"）+ 按需展开的分支 | 日期｜类型｜对象｜issuer｜source_link；分支：分支名｜可观测标志｜验证来源｜受影响指标（indicator_id）｜prev_value |
| ④ 跨资产并列 | 非同质、仅参考 | 对比对｜各自数值｜标注"非同质，仅参考" |
| ⑤ 元信息 | 批次信息 | **as-of（最慢一环的 data_period，L5）**｜observation_time｜calendar_version｜缺失与 stale 清单｜口径提示（comparable_from / caliber_version）｜rule_status 汇总｜**本次输出的证据强度（直接 / 同属性替代 / 跨属性近似）** |
| ⑥ 固定尾句 | 免责声明 | 见第十五节原文 |

> 板块层套同一模板，① 的状态词用第六节板块层词表（C1 偏松/偏紧、C2 份额升/降、C3 偏贵/偏便宜、C4 加杠杆/去杠杆/不可读、C5 增/减、C6 参与度与广度与结构），且 C2、C3 必须带"相对谁"（全市场 / 同类板块）；C4 默认为空环。

### D.1.1 证据行格式（对话默认输出）

每环一行，三段固定顺序：**状态词（数据期）｜依据｜边界**。

```
C2 扩（2026-10）｜依据：M2 同比 7.2% > 0｜边界：不说明资金入市
```

- **状态词**：只能来自 L1 判定表；数据期必填（L5）；板块层必须写"相对谁"与 universe。
- **依据**：写成"字段 = 数值 + 比较"，必须能对上判定表的判据字段与比较基准；替代项要注明口径（如"GC007，场内口径"）。
- **边界**：一句话说明"这个状态不说明什么"，只允许否定式（"不说明…""不等于…"）；不得写成判断（"说明…""意味着…"）。
- 六环按 C1→C6 排列；空环仍出行：`C4 不可读｜依据：无源｜边界：该环无证据`。
- 全页首行 `as-of …（最慢环）`。
- **两种版本**：仪表盘/推送用紧凑版（只有状态词，如"C2 扩；C3 变贵"）；对话与报告用证据行版（本格式）。

### D.1.2 多标的输出结构

一次请求涉及多个标的（多板块、多个股）时：

1. **逐标的独立成节**：每个标的完整跑六环 + 证据行 + 对比层，不合并成一张大表；
2. **节内规则不变**：六环顺序、空环标注、证据行三段照旧；
3. **禁止跨标的比较**：唯一例外是显式 `rank`（`result_form=rank` 且声明 universe，如"申万二级 31 个板块"）——排名只在对比层出现；
4. **as-of 取所有标的中最慢的一环**；各标的 as-of 不同时逐节标注；
5. **标的顺序按请求顺序**，不按表现排序（排序属于判断）。

### D.2 渲染前校验清单（V-清单，任一不过则拒绝输出该区块）

| 校验 | 内容 |
|---|---|
| V-a 字段完整性 | 每条数值带 data_period、source_tier、observation_time；事实记录另须带 subject、channel、proves、does_not_prove；缺一即失败 |
| V-b 图型合规 | series.value_kind 不得为 price；价格类输入必须先转 return（第七节 V1/V2） |
| V-c 锚与算子 | 七锚齐全（含归属锚）；差值/比值类有 operand_order；rank 有 universe；偏离度有 reference；inputs 不得指向 `prev_value`、假设值或分支结果（ADR-022） |
| V-d 禁用词 | 命中 D.3 词表即失败（注册表字段名与指标专名按豁免清单处理） |
| V-e 评价语 | 不含评价词；背离按分组多数规则标注（同向 / 存在背离 / 方向分歧）；环内仅 1 条证据时写“单指标，不适用”；不得出现"背离强度" |
| V-f 事件分支 | 每个分支有 observable_flag 与 observable_flag_source；无概率、无排序可能性、无方向词 |
| V-g 结构合规 | 三项同时校验：① 事实表按 C1→C6→背景排列；② 环内按 subject 分组；③ 空环保留环名并标 missing_type（不得静默跳环）；缺失与 stale 须进入元信息段；stale 阈值按第十节 2（2 倍标 stale、3 倍不可读） |
| V-h 草案标记 | 依赖 draft 条款时元信息段已写 rule_status=draft 与条款编号 |
| V-i 事实层列合规 | 列不在 D.1 ① 的**白名单**内即失败；同比、环比、分位、排名、偏离度、背离为显式示例（ADR-016） |
| V-j 状态词合规 | 证据行三段齐全（状态词+数据期｜依据｜边界），且状态词能按第六节判定表指回"字段 + 比较基准"；指不回去的（活跃/宽松/充裕/偏弱/要涨）即失败；板块层按板块层判定表判定 |
| V-k 因果连词 | 读法句中不得出现 因此/所以/导致/意味着（L4，环间只并列）；出现即失败 |
| V-l 时间基准 | 页首 as-of 必须等于最慢一环的 data_period；每个状态词后须有数据期；方向无前值时必须写"方向待补"（L5） |
| V-m 对手方 | 不得出现接盘/出货/资金从 A 流向 B/外资撤离等叙事；标的级席位明细除外（L6） |
| V-n 证据强度与合成 | 元信息段须写明本次输出的证据强度（直接 / 同属性替代 / 跨属性近似）；出现跨环合成句（如"资金整体在收缩"）即失败（L2、L3） |

### D.3 禁用词表（分类，命中即失败）

- **判断与建议类**：建议、应当、应买入、看多、看空、偏强、偏弱、强势、弱势、低吸、高抛、抄底、逃顶、支撑位、压力位、趋势向上、趋势向下、见底、见顶、反包机会、风险提示、最大风险、反证条件。
- **资金方向结论类**：资金流入、资金流出、净流入、净流出、进场、撤离、加仓、减仓、聪明钱、主力吸筹、出货（作为**结论句**时禁用；作为指标专名如"融资净买入"时按豁免清单处理）。
- **概率与预测类**：大概率、概率、可能、有望、预计、预期、或将、倾向。
- **评分与排序可能性类**：评分、打分、星级、综合得分、可能性排序、最可能。
- **价格结构类**：笔、线段、中枢、背驰、买卖点、走势类型、K 线形态、均线金叉死叉。

**豁免机制：** 指标专名与注册表字段名（如"融资净买入""融资余额增速"）不因字面命中而失败，但豁免清单须在指标注册表中显式登记，不得临场豁免。**分主体净额同样豁免**：按 F18，龙虎榜机构净买、ETF 净申赎、融资余额变化等披露值或可直接相减的值可以呈现，只有把它们合成"总资金净流入"并下方向结论时才失败。

### D.4 渲染契约（三个组件，仅此三个）

图形的作用是**减少阅读负担**，不是增加信息量。以下每条都在防"图变成判断"。

**D.4.0 总则**

1. 只有三个组件：**六环覆盖条**、**序列折线**、**并排小格**。不做仪表盘、不做"市场全景大图"。
2. **默认只出覆盖条**；多标的时加并排小格；**折线必须按需**——用户不说"看走势/最近 N 期"就不画。
3. **每个组件必须绑定一条已存在的证据行**；图不能脱离"依据/边界"单独存在。
4. 图旁必须有 `边界` 文本；图内不得出现结论词、箭头总结、预测带、区间估计。
5. 禁止价格序列形状的图（F03）。

**D.4.1 六环覆盖条（默认必带，一页 1 张）**

字段：`rings[6]`，每项 `{ring: C1–C6, state: has_evidence|substitute|unreadable, evidence_line, note?}`。

规则：按 C1→C6 固定顺序、六环缺一不可；**不可读的环必须出现（灭）**；替代必须半亮并注口径；一页只有一张。

**D.4.2 序列折线（按需，一页最多 1 条）**

触发条件：用户明确要求"看最近 N 期 / 看走势 / 拉一条序列"。

字段：`series_id`、`title`、`x`（data_period 升序）、`y`（compare_value 等长）、`unit`、`value_kind`（`return`/`level`/`ratio`/`count`，**禁 `price`**）、`window`、`as_of`、`evidence_line`、`boundary_text`（否定式，必填）。

禁令：无预测带、无区间估计、不做趋势延长、不标"加速/减速"结论。

**D.4.2.1 画哪条：由判定表指定，系统不挑**

每环的判据字段即其**代表序列**，不做重要性排序：

| 环 | 代表序列 | 次选 |
|---|---|---|
| C1 | LPR 设定值 | 存款准备金率 |
| C2 | M2 同比 | M1 同比；结构附注 = M2−M1 剪刀差 |
| C3 | DR007 | 中国 10Y 国债收益率 |
| C4 | 两融余额 | 客户保证金 |
| C5 | 分主体各一条 | — |
| C6 | 成交额 | 上涨家数占比 |

三种触发：按环、按指标、按比价。**歧义先问**（"利率""成交量"不指环时问一句）。三种情况不画：可比期不足 3 期、`stale` 超 3 倍、窗口跨口径断点。**一页一条**——"看六环走势"不画 6 条线，改用覆盖条。

**D.4.3 并排小格（多标的时必带，一页 1 张）**

字段：`targets[]`，每项 `{name, ring_states[6], visible_count}`。

规则：**只陈列、不比较**——顺序按请求或代码，不按表现排序，不高亮"最好的那个"（排序与高亮都是判断）。

**D.4.4 结构（写入输出，供校验）**

```render
{
  "components": [
    { "type": "rings_coverage", "rings": [ { "ring": "C1", "state": "unreadable", "evidence_line": "C1 不可读（—）" } ] },
    { "type": "series", "series_id": "CMP-001", "value_kind": "level",
      "evidence_line": "C2 结构偏死（2026-10）", "boundary_text": "不说明风险偏好变化" }
  ]
}
```

**D.4.5 校验**

`check.py` 校验：组件在三种之内；覆盖条六环齐全；折线/覆盖条/并排各不超过 1；折线 `value_kind ≠ price`；折线有 `boundary_text`；每个组件（或覆盖条的每一环）的 `evidence_line` 确实出现在输出中。

**D.4.6 禁止清单**

仪表盘；价格序列图（含 OHLCV 分量、base100 曲线）；预测带与区间估计；图内结论词；按表现排序或高亮最优；一张图配多条结论句。

**D.4.7 六环代表序列（`rings_series`）**：六环各取一条代表序列（C1 LPR / C2 M2 同比 / C3 FDR007 / C4 融资余额 / C5 两融投资者 / C6 两市成交额），**每个面板独立纵轴**、标题写明不可跨环比较、禁 price 序列、每面板绑定该环证据行；数据来自 `data/history/`。

**D.4.8 颜色约定**：红=扩/变贵/加杠杆/增/升/强/聚/偏紧/偏活；**蓝**=缩/变便宜/去杠杆/减/降/弱/散/偏松/偏死；无色虚线=不变；浅灰=不可读。颜色只编码方向（不表示好坏/建议）；**事件分支图的环格不许上红白**，只标"受影响"。

**D.4.9 六环卡形态（V2.122.0 固定）**：每环一行、每个判据一块，块内三段 `<状态词> · <指标名> <上期> → <现值>`；箭头固定“上期 → 现值”；单位只写在现值处；无前值不写上期（脚注说明原因）；阈值判定直接用 `<`/`>` 表达；**状态词保持纯词**，数字只在后两段；不可读用浅灰并保留代理值。
